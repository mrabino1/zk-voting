Platform administration

Host this Node

Three approvals: a platform super admin approves platform admins; admins approve election staff; staff register unbounded external eligibility parties for each election (felony, death, age, and any other system that should still be able to reject a ballot after registration). Jurisdictions remain the organizations of this public-good stack. There is no token, no paid tier, and no console that takes fees. Dashboards do not show live vote ticks; public proof of ballots is published once an hour.

Public vote proofs publish at the top of each hour. This console does not show a live jurisdiction increase.
