Election officials

Back office

Clerks stand up elections. Registrars insert identity commitments (never names). Disqualification officers apply the public reason catalog. Election staff register unbounded external parties (felony, death, age, and other systems that do not talk to each other today). Tally operators post counts. Choice plaintext never appears here. Turnout and vote proofs on every dashboard wait until the hour that contained the ballot has closed — a person leaving a voting office cannot be matched to a live increase.

Public ballot counts update once an hour. Officials do not get a live precinct tick.

Election clerk

clerk

Create an election, then freeze the roll before polls open. maxParticipants = 0 means unlimited. Choose plurality (default) or ranked choice (IRV).

If this Node has CHAIN_RPC set, Create election also calls ElectionFactory.createElection and stores the on-chain uint256 id next to the UUID. Factory failures are shown here and nothing is saved locally. Without CHAIN_RPC this form writes republic.json only (demo) and still mints a demo onChainElectionId for the circuit.

0 = unbounded roll.
Election default. YES_NO stays plurality. RANKED questions always use IRV. Created elections get a UUID public id and a short /v/… link; the factory uint256 stays onChainElectionId.
Created elections can be edited until the roll is frozen. Frozen ballots stay hashed as-is.

Person identity

one person · one active ETH

A person is unique. Attest a passkey, Web3 wallet, or smart-card digital ID. Many Ethereum addresses may be internally verified; only one is active. The election Merkle leaf remains an identity commitment — never the active address, never a legal name. Person keys are keccak256 of a civil-file token; this form does not store a name.

External eligibility parties

unbounded

Each election clones its own party registry. Staff may add any number of external systems (felony records, vital statistics, age verification, …). Those systems can still reject a person after registration was approved. The identity commitment is checked, then discarded — it is never stored on the ballot. HTTP oracles are fail-closed: timeout or a non-allow: true response rejects the vote.

If set, every vote POSTs { electionId, identityCommitment }. Must return { allow: true }.

Tally operator

tally_operator

Post per-question plurality counts after cutoff. Each question is tallied on its own options — do not sum every contest into one vector that must equal accepted ballots. Ranked-choice questions are computed with IRV from accepted ranking envelopes (leave the plurality vector blank on an all-ranked ballot). On opens_ballots elections, leave counts blank to open the demo ECIES envelopes, or submit counts that must match the opened ballots — invented partitions are rejected. Threshold-1 operator key is NON-PRODUCTION. If L1_RPC, L1_TALLY_MIRROR_ADDRESS, and L1_PUBLISHER_PRIVATE_KEY are set, the Node also copies keccak256(abi.encodePacked(counts)) to L1TallyMirror. Unset L1 env is a no-op.

Concatenated plurality options in ballot order, or use the per-question fields above. For an all-ranked ballot, leave blank to compute IRV from envelopes. On opens_ballots, omit to derive counts from opened envelopes; invented partitions are rejected. Example YES_NO → [yesCount, noCount].
