# Republic L2

**NOT FOR PROFIT** — civic public good. Not a commercial product. See [`/NOT_FOR_PROFIT.md`](../NOT_FOR_PROFIT.md).

Republic runs **its own ZK rollup**: one sequencer, one prover, settlement on Ethereum L1. Voters get cheap, gasless execution. Courts get L1 state roots and optional tally hashes. There is **no token**.

**chainId `27427`.** Period 2 seconds in `l2/genesis.json`. One sequencer in v1.

Lighter ([lighter.xyz](https://lighter.xyz)) is **prior art** — an application-specific ZK rollup that settles to Ethereum — not the sequencer we operate. Portable EVM bytecode still deploys to Ethereum mainnet and to other EVM L2s if 27427 is unavailable. The product requirement is “L2 like Lighter, plus L1,” with **this** repo’s L2 as the default high-throughput venue.

---

## Why we operate the sequencer and prover

| Control | Why it matters for elections |
| --- | --- |
| No public mempool bidding | Voters are not competing for blockspace with MEV. |
| Paymaster policy | Only election UserOps are sponsored; no general-purpose gas market. |
| Batch contents | Registration, votes, disqualifications, tallies — the explorer can name them. |
| Proof of execution | The L1 `RollupSettlement` contract checks a Groth16 (or mock, in dev) batch proof. Ethereum verifies; the public does not trust an operator’s matching engine. |
| Escape / dispute | Posted `dataHash` lets anyone re-derive the batch from calldata. |

v1 has **one** sequencer. That is a liveness and censorship assumption: a dishonest sequencer can **stall**. It cannot silently change a tally without a proof, and it cannot make a disqualified voter’s proof succeed. Mitigations (L1 inclusion path / timeout, in the spirit of Lighter’s priority/escape design) are in the threat model; they are not an excuse to skip posting batches.

The prover is similarly trusted for **liveness**, not for **correctness**, once real Groth16 keys exist. In development the prover may submit `{accept: true}` mock proofs; **`master` must not**.

## chainId 27427

```text
27427  —  Republic L2 execution
    1  —  Ethereum mainnet settlement (and optional L1TallyMirror)
```

Use 27427 in:

- `l2/genesis.json`
- Node / `packages/types` `REPUBLIC_CHAIN_ID`
- Wallet / viem `chain` objects when talking to the local sequencer
- Replay protection for vote messages (a proof bound to `electionId` still must not be replayed on another chain; contracts should see `block.chainid`)

Do not reuse 27427 for a forked “Republic commercial L2.” This chain id names the **not-for-profit** civic rollup in this repository.

## Components

```text
l2/
  genesis.json          chainId 27427, 2s period, 1 sequencer
  config.json           RPC URLs, settlement address, sequencer/prover keys (dev)
  sequencer/index.mjs   JSON-RPC subset + block production
  prover/index.mjs      per-batch state root + proof + submitBatch
  README.md             operator notes (also NOT FOR PROFIT)
```

### Sequencer

- Accepts `eth_*` JSON-RPC the Node, bundler, and explorer need (`eth_chainId`, `eth_getBlockByNumber`, `eth_getLogs`, `eth_call`, `eth_sendRawTransaction` / UserOp endpoint as implemented).
- In development **may proxy EVM execution to Anvil** so Foundry-deployed contracts run unchanged.
- Produces blocks on the genesis period (2s). Transaction list is public.
- Does not require voters to hold a gas token. Paymaster + bundler attach to sponsored UserOps.

### Prover

For each batch:

1. Compute `prevStateRoot` → `newStateRoot`.
2. Hash batch calldata → `dataHash`.
3. Produce a proof:
   - **dev / `test/unstable`:** mock `{accept: true}` compatible with `MockVerifier`.
   - **production / `master`:** Groth16 (or the rollup’s chosen SNARK) against keys that match the settlement verifier.
4. Call L1 `RollupSettlement.submitBatch(batchIndex, prevStateRoot, newStateRoot, dataHash, a, b, c)`.

Only sequencer / prover addresses authorized on the settlement contract may submit. Batches are public.

### Settlement contract (L1)

`smart-contracts/src/l2/RollupSettlement.sol`:

```solidity
function submitBatch(
    uint64 batchIndex,
    bytes32 prevStateRoot,
    bytes32 newStateRoot,
    bytes32 dataHash,
    uint256[2] a, uint256[2][2] b, uint256[2] c
) external;

function stateRoot() external view returns (bytes32);
function batchCount() external view returns (uint64);
```

`L1TallyMirror.sol` copies a **tallied** election result hash from L2 to L1 when the jurisdiction asked for court-grade L1 records.

## Gas and money

- Voters: **zero**. No L2 token, no “vote fee.”
- Jurisdiction: funds the paymaster and the sequencer/prover host **at cost**.
- No admin-skimmable ETH except that sponsorship.
- Development elections may use Anvil’s default funded accounts for the sequencer, never for “the voter pays.”

## How to run (dev)

```bash
# From repo root, after contracts are deployed to Anvil (or the sequencer’s EVM)
npm run l2:sequencer    # node l2/sequencer/index.mjs
npm run l2:prover       # node l2/prover/index.mjs
```

Point the Node at the sequencer RPC (`REPUBLIC_RPC_URL`, default `http://127.0.0.1:8545` in `packages/chain-client`). Set `REPUBLIC_CHAIN_ID=27427`.

`l2/data/` is gitignored. Do not commit sequencer keys.

Foundry scripts: `DeployL2.s.sol` (factory, election stack, paymaster on 27427), `DeployL1.s.sol` (settlement + optional factory / tally mirror).

## Explorer and privacy

Every block’s **outcomes** are visible: registrations (commitments), votes (nullifiers + ballot hashes), disqualifications (reason codes), tallies, batches. Choices are not.

Vote transactions stay in a **sealed** mempool until the hour that contained them has closed. `eth_getBlockByNumber("pending")` and `eth_getTransactionByHash` do not reveal sealed votes. Once the hour closes they are mined in one lumped block, ordered by hash, with the block timestamp at the disclosure clock — not the minute the voter left the office. See [`BLOCK_EXPLORER.md`](./BLOCK_EXPLORER.md).

Censorship: if the sequencer omits a valid vote UserOp, that is a liveness/censorship failure. It should be observable (the voter has a receipt of the UserOp hash the bundler accepted, or a rejection). It is **not** fixable by putting the choice on L1 in the clear.
