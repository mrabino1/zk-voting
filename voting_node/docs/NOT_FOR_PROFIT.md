# NOT FOR PROFIT

**This software is not a commercial product.**

ZK-Voting (repo `zk-voting`; product name renameable in site admin) exists to protect and preserve a
democratic republic: the people vote for representatives, and
those representatives vote. It is written so that a city, county, state,
nation, or any body that must run a binding election — including replacing
every publicly traded company's shareholder vote if a jurisdiction demanded
it — can do so with **public verifiability** and **private ballots**.

There is no token. There is no paid tier. There is no vendor lock-in.
Nobody is to make money off this repository.

## Labels that must appear

Every document in this repository (README, architecture, operator guides,
API docs, circuit notes, L2 notes) must carry a visible **NOT FOR PROFIT**
label near the top.

Smart contract source files carry:

```
// NOT FOR PROFIT — civic public good, not a commercial product.
```

## What this forbids

- Selling this software, hosting it as a paid SaaS, or wrapping it in a
  token / DAO that extracts fees from voters or jurisdictions.
- Dark-pattern monetization of registration, gas, or tallying.
- Using voter data as a product.

## What this allows

- A government, county clerk, union, or cooperative running it at cost.
- Volunteers and public-interest engineers improving it.
- Academic use, audits, and court-facing verification.

If you want to get rich, this is the wrong repository.
